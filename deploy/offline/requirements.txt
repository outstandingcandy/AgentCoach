# Offline GoalInsight pipeline — full dependency set for a self-
# contained Docker image. Lives separately from the top-level
# requirements.txt because:
#   * we drop the web app (fastapi/uvicorn/python-multipart) — the
#     image is CLI-only, no /pipeline /match /annotate UIs.
#   * we drop test deps (pytest) — image is for end-users, not the
#     CI runner.
#   * we keep the heavy ones (mmocr family, sam2, open_clip,
#     transformers, qwen-vl-utils) so any jersey-OCR backend works
#     out of the box without a second install pass.
#
# Pinned PyTorch family lives in the base image (pytorch:2.4.1-
# cuda12.1-cudnn9-runtime); do NOT re-pin here or pip will re-resolve
# and break CUDA wheels.
