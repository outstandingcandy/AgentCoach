# Offline GoalInsight pipeline — full dependency set for a self-
# contained Docker image. Versions mirror the dev venv at the repo
# root (the one in `.venv/`) — they're known-good against the
# repo's source tree as of the latest tested run.
#
# Drops vs repo's top-level requirements.txt:
#   * fastapi / uvicorn / python-multipart — image is CLI-only
#   * pytest — image is for end users, not CI
#   * sam2 — declared in the repo's top-level requirements for future
#     segmentation work but not imported by any current pipeline stage,
#     and sam2>=1.1 demands torch>=2.5 which pip resolves into a wider
#     torch upgrade than we want at build time
#   * mmocr family — needs a from-source mmcv compile against torch
#     headers (C++17, ~15 min build time, ~1 GB image bloat). Users
#     who want OCR-based jersey reading should set
#     ``track_consolidation.jersey.backend`` to claude / gemini /
#     qwen and pass the matching API key at ``docker run`` time.

# Detection & Tracking
ultralytics==8.4.60
sahi==0.12.0
deep-sort-realtime==1.3.2

# ReID
# torchreid 0.2.5 (the PyPI fork) imports gdown + tensorboard at
# package init via torchreid.reid.engine — but doesn't declare them
# in its setup.py. Listing them explicitly here so `import torchreid`
# works in a fresh image (otherwise OSNetExtractor silently treats
# torchreid as missing and the build fails at the weight pre-bake step).

#   * ``vllm`` — track_consolidation spawns a local vLLM server on-demand
#     (only during that stage) so the pipeline's other GPU-heavy stages
#     don't compete with a permanent LLM daemon for VRAM. See
#     ``goalinsight/track_consolidation/_runner.py::_launch_vllm_daemon_if_needed``.
